# Lumos

Приложение для Windows 10/11 x64: управление гаммой, яркостью, контрастом, балансом цвета, профилями игр и аппаратной резкостью DDC/CI.

Текущая версия: **Alpha 0.0.10**. Требуется .NET Framework 4.5 или новее (входит в современные версии Windows).

## Установка

Откройте [Releases](https://github.com/ikSleepMode/Lumos/releases), скачайте `Lumos-Setup.msi` и запустите установщик. Перед обновлением старой версии завершите Lumos через значок в трее. Профили и настройки пользователя сохраняются в LocalAppData/LumaDesk и не входят в установщик.

## Активация

Начиная с Alpha 0.0.10 требуется код доступа, привязанный к устройству. При первом запуске отправьте владельцу код устройства из окна активации, получите ответный код и вставьте его целиком. Владелец задаёт дату и время окончания; код не начинает новый отсчёт при повторном вводе. Срок отображается в локальном часовом поясе Windows.

Приложение использует SHA-256 отпечаток SMBIOS UUID (при его отсутствии — MachineGuid Windows), исходные идентификаторы не включаются в код запроса и не передаются автоматически. Ответный код подписан RSA-3072/SHA-256. Секретный ключ выдачи не находится в этом репозитории и не входит в сборку приложения.

Активация хранится в `%LOCALAPPDATA%/LumaDesk/activation.bin`, защищена DPAPI текущего пользователя Windows и сохраняется при обновлении. При смене UUID устройства, переустановке Windows при использовании MachineGuid или смене пользователя может потребоваться повторная активация. Для продления откройте настройки → «Продлить активацию».

Срок проверяется при запуске и каждые 15 секунд во время работы. При истечении срока основное окно закрывается, Lumos пытается восстановить экран штатным механизмом, затем показывает активацию. До успешной активации основной движок коррекции не создаётся.

Это офлайн-контроль доступа: мгновенного отзыва нет. Сохранённое максимальное время обнаруживает обычный перевод часов назад, но не гарантирует защиту при удалении состояния, восстановлении снимка системы или изменении программы. Цифровая подпись предотвращает подделку кодов без секретного ключа, но не устраняет возможность изменения исполняемого файла. Старые версии до 0.0.9 включительно остаются без активации.

## Обновления

Lumos автоматически проверяет GitHub Releases при запуске. В настройках ⚙ доступны кнопки «Проверить обновления» и «Скачать и установить». Альфа-канал включает предварительные релизы. При появлении обновления приложение показывает уведомление в строке состояния; скачивание начинается по нажатию кнопки.

Загружается только `Lumos-Setup.msi` из этого репозитория по HTTPS. Перед запуском проверяются размер и SHA-256 из GitHub API. Подтверждение открывает обычный установщик Windows и завершает Lumos с восстановлением экрана. После установки откройте Lumos через ярлык. Если сети нет, приложение продолжает работать; проверку можно повторить вручную. Портативную версию обновляйте вручную из Releases.

Проверка SHA-256 защищает от повреждения загрузки, но не заменяет подпись издателя. Установщик пока не подписан сертификатом Authenticode.

## Сборка

На Windows, в PowerShell:

```powershell
./scripts/test.ps1
./scripts/build.ps1
```

Результат: `dist/Lumos.exe` и `dist/Lumos-Setup.msi`. Внешние пакеты и SDK не требуются; используются компилятор .NET Framework и Windows Installer.

## Выпуск следующей версии

1. Измените `AssemblyVersion`, `AssemblyFileVersion`, `AssemblyInformationalVersion` в `src/LumaDesk.Version.cs`, версию в `src/LumaDesk.manifest` и текст версии в `src/Studio.xaml`.
2. Проверьте сборку и сохраните изменения в ветке main.
3. Создайте и отправьте тег, например `v0.0.11-alpha`:

```powershell
git tag v0.0.11-alpha
git push origin main v0.0.11-alpha
```

GitHub Actions проверит соответствие тега версии, запустит тесты, соберёт EXE/MSI и создаст предварительный релиз. Установленные приложения с поддержкой обновлений увидят новый релиз при следующем запуске или ручной проверке.
